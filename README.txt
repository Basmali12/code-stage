CodeStage — استوديو برمجة محلي للتصوير

تصاميم المتاجر الستة:
1. TechZone — أبيض وأزرق.
2. EliteTech — أسود وذهبي.
3. SmartMall — مرجاني مرح.
4. GreenTech — أخضر هادئ.
5. NovaTech — بنفسجي مضيء.
6. GearUp — أبيض وأسود ولايم.
افتح الإعدادات، اختار بطاقة التصميم، ثم احفظ. تغيير التصميم يبدأ البناء من الصفر.
يحفظ اختيارك محلياً حسب سماح المتصفح.
لكل تصميم أربعة أقسام وستة منتجات بالصور وبنرات ثلاثة تتبدل كل 4 ثوانٍ من اليسار لليمين.
تبدأ حركة البنرات من مرحلة بناء البنر. تتفعل أدوات البحث والمفضلة والسلة عند اكتمال المشهد.
صور المنتجات والبنرات مضمنة محلياً، والنسخة المصدرة تحتوي الصور أيضاً ولا تحتاج اتصالاً.
التصاميم مستوحاة من اللوحة المرجعية مع إعادة بناء العناصر كواجهات تفاعلية، وليست صورة ثابتة للوحة.

الكود المعروض في محرر التصوير: React + TypeScript + Tailwind CSS.
الملفات: Storefront.tsx وcomponents.tsx وstore.ts، وتوجد نسخ منها بمجلد react-source.
المعاينة المحلية محاكاة معدة مسبقاً، ولا تنفذ عملية ترجمة React أثناء الكتابة.
محرك الاستوديو نفسه يعمل بملفات ويب محلية. تصدير المتجر يحفظ نسخة HTML مستقلة من المعاينة.
يظهر المتجر على مراحل: الهوية والبحث، التبويبات، البنر، الأقسام، المنتجات، العروض والتذييل، ثم تفعيل البحث والتصفية والسلة التجريبية.
نسبة البنر 2.35:1. مساحة المحرر ثابتة وتتبع مؤشر الكتابة مع إبقائه ظاهراً.
إيقاع الكتابة الافتراضي: كلمة كل ضغطتين، مع إظهار جزء من الكلمة بكل ضغطة.
يمكن اختيار كلمة بكل ضغطة من الإعدادات. عرض إطار الهاتف 300 بكسل.
بعد تحديث الملفات اضغط Ctrl+R ثم إعادة المشهد.

افتح index.html مباشرة. لا يحتاج إنترنت أو حساباً أو ذكاءً اصطناعياً.
لتثبيت اختصار يفتح البرنامج بنافذة مستقلة، شغّل Install.cmd.
يستخدم الاختصار Microsoft Edge. احتفظ بمجلد البرنامج بمكانه بعد التثبيت.

انقر داخل المحرر واكتب أي أحرف لتكشف كوداً معداً مسبقاً.
اضغط Backspace للرجوع. عند إكمال ملف، الضغطة التالية تنتقل إلى التالي.
يمكن تبديل الملفات يدوياً من التبويبات. يتطور المشهد وفق تقدم الملفات.
أكمل Storefront.tsx ثم components.tsx ثم store.ts حتى يكتمل المتجر التجريبي.
F8: وضع التصوير وشاشة كاملة. Esc: الرجوع.
الإعدادات: اسم المتجر ولونه وسرعة ظهور الحروف.
تصدير المتجر: تنزيل صفحة HTML مستقلة تعمل بدون إنترنت.

هذا محرر محاكاة للتصوير بكود معد مسبقاً، وليس مولد برامج من الكلام.
معاينة المتجر تعمل داخل الصفحة؛ عنوان localhost الظاهر جزء من تصميم المشهد.
السلة تجريبية في الذاكرة، ولا توجد مبيعات أو دفع أو قاعدة بيانات.
لا يحفظ تقدم الكتابة بعد إغلاق البرنامج؛ يحفظ إعدادات الاسم واللون والسرعة حسب سماح المتصفح.
للإزالة احذف اختصار CodeStage من سطح المكتب. لا يثبت خدمات أو يبدأ تلقائياً مع ويندوز.
